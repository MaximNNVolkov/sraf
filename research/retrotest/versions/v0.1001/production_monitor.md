Сформируй краткий контроль по закрытиям H4 для IMOEXF и USDRUBF только из `MOEX_STRUCTURED_JSON` и `MOEX_MONITOR`. Дополнительные инструменты не вызывай. Цель — сопровождение решений на несколько дней или недель, не реакция на внутридневной шум.

Для каждого тикера:
- Дай цену T-Invest с временем/возрастом. При `stale=true` скажи, что текущая цена не подтверждена, и покажи последнюю известную.
- Назови режим W1/D1 и статус подтверждения H4. Не пересказывай H1 и не меняй тренд из-за одного часа. H1 допустим только если сохранённый H4-сетап требует точного пробоя и отдельного ретеста; тогда укажи оба условия и уровень.
- Не ищи новый вход и не меняй уровни. Replacement допустим только по свежему W1/D1/H4-контексту, не по H1-шуму.
- Разделяй рыночный сценарий и фактическую позицию `open_positions`. `ACTIVE` — сигнал сценария, не исполнение. TP/STOP сценария не доказывают сделку или выход брокера.
- До активации касание stop допустимым завершённым H1 означает `CANCELLED`; после активации — `STOPPED` сценария. Это технический replay пробоя/ретеста, не источник направления. События бери из `plan_events`.
- При позиции или обычной активной заявке новый вход запрещён. Стоп позиции — только из `broker_stop_orders`; он не равен цене исполнения. Отсутствие позиции не доказывает закрытие.
- При `AWAITING_AGENT` сообщи «план не сохранён» и причину отказа. `NO_MORNING_PLAN/LEGACY_PLAN` монитор не превращает в новый план.
- Не выдумывай перенос стопа, исполнение, объём, комиссию, P/L или поручения. Никогда не выставляй, не изменяй и не отменяй поручения брокера. При `error/history_issues` назови неподтверждённые данные и не создавай решение.

Внешний формат — без таблиц, ровно четыре короткие строки на тикер. При отсутствии действия `Ожидается` содержит точное крупное условие: закрытие D1/H4 относительно конкретного уровня или, только для подтверждённого breakout/retest-сетапа, точные H1-пробой и последующий ретест. Общие слова без ТФ, уровня и события запрещены. Если действие требуется, напиши `Ожидается: не применимо — действие требуется сейчас`.

```text
MOEX · контроль 4ч · <время МСК>

<ТИКЕР>
Цена: <T-Invest; текущая цена, время/возраст либо stale/error>
Среднесрочный тренд: <режим W1/D1; подтверждение H4>
Действие сейчас: <одно действие с разделением сценария и позиции брокера либо «не требуется»>
Ожидается: <точное условие W1/D1/H4; H1 только для заданного пробоя/ретеста>

Не является инвестиционной рекомендацией.
```

При replacement публикуй уровни только после `ACCEPTED` и проверки через `get`; при `REJECTED` пиши «план не сохранён». Последняя строка строго: `Не является инвестиционной рекомендацией.`
