# USDRUBF v0.1001: исторический агент

Это исследовательский replay, не детерминированный baseline и не реальная торговля.
Используй правила анализа из production_morning.md / production_monitor.md, но
все данные, время и состояние получай только из retrotest backend. Не запускай
продуктивные скрипты и команды брокера. Не запрашивай внешнюю историю и не используй
известное тебе последующее развитие рынка. Отдельная сессия/контекст модели на run.

В 08:00 изучи W1/D1/H4/H1, сформулируй PLAN с LONG/SHORT, entry (ориентиром),
stop, tp1, tp2, точным entry_condition, reason и analysis. Если условий нет —
NO_TRADE с reason и условием ожидания. На следующем мониторинге решение можно
пересмотреть, пока нет запланированного/фактического входа.

Backend advance передвигает время на 2 часа до 20:00, затем на 08:00 следующей
наблюдаемой торговой даты. Утренний контекст содержит продовые признаки;
new_h1_candles — только завершённые новые H1 (на переходе через ночь их может
быть больше двух; пропуски/неторговые интервалы не заполняются).

Только когда ты по доступным свечам подтвердил ранее описанное условие, отправь
CONFIRM_ENTRY с reason и evidence (времена свечей, пробой, ретест). Backend не
подменяет это решение механическим касанием entry. CONFIRM_ENTRY допустим на
мониторинге после 08:00 при существующем PLAN. Сохраняй полный запрос и ответ
модели, её точный идентификатор и параметры в metadata решения.

Подтверждение в T планирует вход на T+15 минут по close свечи [T,T+15).
Цена пока недоступна агенту; появится только при advance. Если свечи нет или
цена уже за stop/TP1, вход отменяется с явной причиной. Начальный ориентир
entry не подменяет фактическую цену.

После входа уровни заморожены: 50% закрываются по TP1, стоп остатка переносится
на фактический entry. Дальнейший выход — TP2 или stop. Backend следит по M1
во всех сессиях, включая ночь и часы между мониторингами. Случаи без точного
порядка на M1 остаются AMBIGUOUS. Время события внутри бара — интервал,
а не выдуманная секунда. Проценты — gross к цене входа, не доходность счёта;
net без конфигурации издержек отсутствует.
