# Слайды бизнес-процесса

Все слайды делаются на общей теме и движке — не пиши стили и JS с нуля.

| Файл | Назначение |
|---|---|
| `assets/theme.css` | цвета, типографика, сетки, компоненты, анимации |
| `assets/deck.js` | масштабирование холста, навигация, номера страниц, перезапуск анимаций |
| `templates/title.html` | титульный слайд |
| `templates/table.html` | таблица этапов со статусами и прогрессом |
| `templates/theses.html` | 4 тезиса-карточки + итог |
| `templates/layouts.html` | текст + визуал, KPI, шаги процесса, «было/стало» |
| `scripts/check_layout.mjs` (в папке скилла) | автоматическая проверка компоновки |

Перед работой прочитай `assets/theme.css` и шаблон, ближайший к задаче. Копируй разметку из шаблонов и меняй содержимое — так стиль останется единым.

## Порядок работы

1. **Разложи содержание по слайдам.** Одна мысль — один слайд. Если материала больше лимитов (см. ниже) — дели на несколько слайдов, а не уменьшай шрифт.
2. **Для каждого слайда выбери макет** по таблице «Какой макет выбрать».
3. **Собери файл** в `decks/<название>.html` (если пользователь не указал другое место). Скелет — ниже; пути к ассетам — `../assets/…`. Порядок `<section class="slide">` = порядок слайдов.
4. **Проверь компоновку** — `npm run check -- decks/<файл>.html`. Исправь все ✖, по возможности и ⚠.
5. **Посмотри скриншоты** из `slide-check/` (инструментом Read) — каждый слайд. Скрипт не видит смысловых проблем: неудачные переносы, пустые ячейки, некрасивые пропорции.
6. Повторяй 4–5, пока ошибок нет и слайды выглядят аккуратно.

Если `npm run check` падает с «Не найден пакет playwright» — выполни `npm install` в корне репозитория. Путь к Chromium можно задать через `CHROME_PATH`.

## Скелет файла и контентного слайда

```html
<!doctype html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Название презентации</title>
  <link rel="preconnect" href="https://fonts.googleapis.com">
  <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
  <link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700;800&display=swap">
  <link rel="stylesheet" href="../assets/theme.css">
</head>
<body>

  <section class="slide" aria-label="Короткое имя слайда">
    <div class="corner-deco"></div>
    <div class="content">
      <div class="slide-header">
        <div>
          <div class="eyebrow a fade-left" style="--d:.1">Раздел</div>
          <h2 class="slide-title a fade-up" style="--d:.2">Заголовок-мысль</h2>
          <!-- необязательно: <p class="slide-lead a fade-up" style="--d:.3">Пояснение</p> -->
        </div>
      </div>
      <div class="header-rule a grow-x" style="--d:.35"></div>

      <div class="body">
        <!-- ОДИН главный блок на всю ширину: .grid-*, .split, .steps, .table-wrap, .theses
             (+ при необходимости .takeaway или .table-note под ним) -->
      </div>
    </div>

    <footer class="slide-footer a fade-in" style="--d:.3">
      <div class="brand"><span class="logo-mark"></span>Название компании</div>
      <span class="page-num" data-page></span>
    </footer>
  </section>

  <script src="../assets/deck.js"></script>
</body>
</html>
```

Титульный слайд (`.slide--title`) копируй целиком из `templates/title.html`: у него своя абсолютная раскладка (текст слева, схема процесса справа, мета-данные снизу).

## Правила компоновки — главное

Холст 1920×1080. Рабочая область контентного слайда — 1680px по ширине (отступы 120px слева и справа).

```
y=96   ┌ шапка: eyebrow + заголовок (+ lead) ────────────────┐
       ├ header-rule ────────────────────────────────────────┤
       │ .body — всё оставшееся место; содержимое центруется │
       │ по вертикали; главный блок растянут на 1680px       │
y≈950  └─────────────────────────────────────────────────────┘
y≈1004   футер: бренд слева, номер страницы справа
```

1. **Контент занимает всю ширину.** Главный блок в `.body` — это сетка или компонент на 100% ширины. Никогда не оставляй одиночный список, абзац или картинку в левой части с пустой правой половиной. Если текста мало — используй `.split` (текст + визуал/KPI) или колонки `.grid-2/3`.
2. **Баланс лево/право.** Левая и правая половины должны быть заполнены примерно одинаково (скрипт ругается при перекосе больше 75/25). Шапка выровнена влево — это нормально, балансировать нужно тело слайда.
3. **Вертикаль заполнена.** Содержимое `.body` должно занимать хотя бы ~50% его высоты. Мало контента → крупнее элементы (KPI, карточки), добавь `.takeaway`-вывод или визуал. Много → раздели слайд.
4. **Ничего не выходит за края** и не наезжает на футер. `.body > *` не сжимается, поэтому переполнение сразу видно — не лечи его `overflow:hidden` или уменьшением шрифта ниже минимума.
5. **Равные колонки.** В сетке — элементы одного типа и близкого объёма текста; число элементов кратно числу колонок (4 → 2×2, 6 → 3×2, а не 5 в `grid-2`).
6. **Не используй** абсолютное позиционирование, фиксированные `width`/`margin-left` для раскладки контента и собственные отступы у дочерних элементов `.body` — промежутки задаёт `gap`.

### Какой макет выбрать

| Содержание | Макет | Образец |
|---|---|---|
| Название, докладчик, дата | `.slide--title` | `title.html` |
| Этапы с атрибутами (≤ 6 строк × ≤ 5 колонок) | `.table-wrap > .data-table` + `.table-note` | `table.html` |
| 4 тезиса + вывод | `.theses` (2×2) + `.takeaway` | `theses.html` |
| 2 тезиса / сравнение «было/стало» | `.grid.grid-2.stretch` с `.card` | `layouts.html`, слайд 4 |
| 3 тезиса или 3 цифры | `.grid.grid-3` с `.card` / `.kpi` | `layouts.html`, слайд 2 |
| 4 цифры | `.grid.grid-4` с `.kpi` | — |
| Список 3–5 пунктов + график/схема | `.split` : `.bullets` + `.visual` | `layouts.html`, слайд 1 |
| Последовательность 3–6 шагов | `.steps > .step-item` | `layouts.html`, слайд 3 |
| Одна ключевая мысль | `.split.split--even`: крупный `.kpi` + `.card` с пояснением | — |

### Лимиты текста

| Элемент | Лимит |
|---|---|
| Заголовок слайда | до ~45 символов, 1 строка (макс. 2) |
| eyebrow | 1–3 слова |
| lead | 1 строка, до ~80 символов |
| Заголовок карточки/тезиса | до ~30 символов |
| Текст карточки | до ~110 символов |
| Пункт `.bullets` | до ~90 символов, не больше 5 пунктов в колонке |
| Строк таблицы | до 6 (с `lead` — до 5) |

Минимальный размер шрифта — 20px (подписи), основной текст — 24–30px. Шрифты не уменьшай, чтобы «влезло» — сокращай текст или дели слайд.

## Стиль

- Цвета только через переменные `:root` из `theme.css` (`--ink`, `--muted`, `--accent`, `--accent-2`, `--warn`, `--danger`, `--line`, `--soft`, `--navy-*`). Новые цвета не вводи.
- Акцентный градиент — `linear-gradient(135deg, var(--accent), var(--accent-2))`: номера, маркеры, полосы прогресса, выделения.
- Статусы — пилюли `.pill--done / --work / --risk / --plan`.
- Скругления: карточки 24px, мелкие элементы 12–18px, пилюли 999px.
- Заголовок-мысль, а не тема: «Цикл закупки сократится вдвое», а не «Результаты».
- Если нужен новый компонент — добавь его в `theme.css` в том же стиле (токены, скругления, тени как у `.card`), а не инлайн-стилями.

## Анимации

- Каждому содержательному элементу — класс `a` + тип и задержка `--d` (секунды): `class="a fade-up" style="--d:.5"`.
- Типы: `fade-up` (по умолчанию для блоков), `fade-left`/`fade-right` (колонки, строки), `zoom-in` (таблица, визуал), `grow-x` (линии, полосы прогресса), `pop` (номера, иконки), `draw` (SVG-линии с `pathLength="1000"`), `fade-in` (футер, подписи).
- Порядок: сверху вниз, слева направо. Шапка 0.1–0.4, тело с 0.5, шаг между соседними элементами 0.1–0.15. Вся анимация слайда укладывается в ~2 с.
- Декоративные элементы (фон, пятна, сетка) помечай классами `.blob`, `.corner-deco`, `.title-grid` или атрибутом `data-deco` — проверка их не учитывает.

## Что проверяет скрипт

`scripts/check_layout.mjs` отключает анимации, рендерит каждый слайд в 1920×1080 и выводит:

- ✖ **выходит за край слайда** — элемент за пределами безопасной зоны;
- ✖ **содержимое обрезано** — переполнение внутри блока с `overflow`;
- ✖ **текст наезжает на другой текст**;
- ✖ **контент занимает только N% ширины** — меньше 75% рабочей области;
- ✖ **контент смещён влево/вправо** — больше 75% заполнения на одной половине (⚠ от 67%);
- ✖ **не помещается по высоте**; ⚠ **занимает N% высоты** — меньше 50%;
- ⚠ **мелкий шрифт** — меньше 20px.

Скриншоты — `slide-check/slide-NN.png` (или `--out <папка>`). Готово — когда ошибок 0 и скриншоты просмотрены.
