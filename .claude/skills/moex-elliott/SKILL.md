# Среднесрочная сводка по инструменту MOEX

Аргумент — тикер MOEX (`SECID`). Если он неоднозначен, задай один уточняющий
вопрос. Отвечай по-русски, кратко и без таблиц. Прочитай
`prompts/moex_elliott.md` и файл особенностей инструмента, если он существует.

## Данные

Основной источник — T-Invest; ISS допустим только по явному `--source iss`.

```sh
.venv/bin/python scripts/tf_report.py $S
.venv/bin/python -m usdrubf --secid $S quote
.venv/bin/python -m usdrubf --secid $S chart --png -t 240 -t 1440
```

Проверяй источник, тикер, режим торгов и время цены. Используй только завершённые
свечи. При недоступных или устаревших данных сообщи это и не создавай торговое
решение из неполного контекста. Цифры не додумывай.

Для IMOEXF/USDRUBF прочитай `docs/STRATEGY.md` и `docs/AGENT_PROTOCOL.md`.
Используй уже переданный утренний контекст. Решение фиксируется через `submit`,
проверяется через `get` и существует только после `ACCEPTED`/`REVIEWED`.

## Анализ и решение

- W1 задаёт режим; D1 задаёт направление, волатильность и условие смены режима;
  H4 подтверждает сетап, структуру и торговые уровни.
- Волны и индикаторы — контекст, не самостоятельный сигнал. Проверяй разметку на
  W1/D1/H4 и отделяй гипотезу от подтверждённых фактов.
- H1 не выбирает направление или новый сетап. H1 допустим только для закрытого
  пробоя конкретного уровня и отдельного последующего ретеста уже подтверждённого
  H4-сетапа.
- Выбери один `LONG_SETUP`, `SHORT_SETUP`, `NO_TRADE`, либо `KEEP_PLAN`, если
  план уже сохранён. Направленный план требует подтверждения H4 и R/R до TP2 не
  ниже 1:2.
- `NO_TRADE` обязан назвать в `reason` точное ожидаемое условие: D1 или H4,
  конкретный числовой уровень и событие закрытия, пробоя, возврата или ретеста.
  Это ограничение не относится к `KEEP_PLAN`.

Не выставляй, не изменяй и не отменяй поручения брокера. `ACTIVE` — состояние
сценария, не сделка; фактическую позицию бери только из брокерского снимка.

## Ответ

Следуй разделу 7 `prompts/moex_elliott.md`: цена; тренд W1/D1 с подтверждением H4;
сценарий отдельно от позиции; действие; точное ожидаемое D1/H4-условие. Без таблиц.
H1 упоминай только для заданной механики пробоя/ретеста. При `NO_TRADE` напиши
«нет сделки». Графики, если нужны, строй только на H4/D1.

Во время сводки ничего не коммить, не пушь и не создавай PR.
