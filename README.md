# MOEX ISS — данные и анализ по Эллиотту для любого инструмента

Интеграция с ISS Московской биржи (`https://iss.moex.com`) и вспомогательный анализ для торгового
агента. Работает с любым тикером: фьючерсы, акции, валюта, индексы, облигации. По умолчанию
используется вечный фьючерс USDRUBF. Рынок и режим торгов CLI определяет сам (основной режим в ISS),
их можно задать явно флагами `--engine/--market/--board`.
Только стандартная библиотека Python 3.10+, ключ API не нужен.

```
python3 -m usdrubf quote                       # котировка (JSON): last, bid/offer, OI, время сделки
python3 -m usdrubf candles -t 60 --from 2026-10-01   # свечи CSV: 1/5/10/15/30/60/240 мин, 1440 — день
python3 -m usdrubf report                      # сводка для агента (Markdown), --json — JSON, -o файл
python3 -m usdrubf chart --png               # графики 1ч и 1д (SVG + PNG) в charts/<тикер>_1h|1d: свечи, MA50/200, зигзаг, уровни
python3 -m usdrubf chart --png --waves 60=0,A,B,C --level 80.90:"вход 80.90":blue --level 81.20:"стоп 81.20":gray
python3 -m usdrubf --secid SBER report          # любой тикер: SBER, CNYRUB_TOM, IMOEX, SiZ6…
python3 -m usdrubf --secid SBER --board SMAL quote   # явно заданный режим торгов
python3 -m unittest discover -s tests          # тесты (без сети)
```

- `usdrubf/moex.py` — клиент ISS: выбор режима торгов, котировка (для индексов — значение индекса), свечи с пагинацией, ресемплинг
  (ISS отдаёт 1, 10, 60 мин и дни; 15 мин собираются из минуток).
- `usdrubf/analysis.py` — MA, RSI14 (Уайлдер), ATR14, зигзаг-экстремумы, уровни,
  проверка обязательных правил Эллиотта и соотношений волн.
- `usdrubf/report.py` — сводка: котировка с оценкой свежести, свечи 1ч и 1д, кандидаты разметки.
- `usdrubf/chart.py` — SVG-график: свечи, MA50/MA200, зигзаг с подписями волн, уровни плана.
  `--waves ТФ=…` подписывает последние экстремумы зигзага, `--level ЦЕНА:ПОДПИСЬ[:ЦВЕТ]` рисует уровни
  (если задан хотя бы один — автоуровни не рисуются). PNG — через headless Chromium, rsvg-convert или ImageMagick.
- `prompts/moex_elliott.md` — промпт торгового агента для любого тикера (`{SECID}`);
  `prompts/usdrubf_elliott.md` — особенности USDRUBF.
- Навыки: `.claude/skills/moex-elliott` — сводка по любому тикеру; `.claude/skills/usdrubf-morning` —
  утренняя сводка USDRUBF (обёртка над `moex-elliott`).
- `docs/HANDOFF.md` — описание проекта для передачи другим агентам.

Ограничения: без авторизации ISS отдаёт данные с задержкой ~15 минут — сводка
всегда показывает время последней сделки. Все времена — МСК. Автоматическая
волновая разметка вспомогательная: последний экстремум зигзага не подтверждён.
