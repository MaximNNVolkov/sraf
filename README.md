# Шаблоны слайдов для бизнес-процесса

HTML-слайды 16:9 (холст 1920×1080) с анимацией появления элементов.

| Файл | Что внутри |
|---|---|
| `templates/title.html` | Титульный слайд: название, подзаголовок, докладчик, анимированная схема процесса |
| `templates/table.html` | Слайд с таблицей: этапы, ответственные, сроки, прогресс-бары, статусы |
| `templates/theses.html` | Слайд с тезисами: 4 карточки и итоговый вывод |
| `index.html` | Демо-презентация из всех трёх слайдов |
| `assets/theme.css` | Цвета, типографика, анимации |
| `assets/deck.js` | Масштабирование, навигация, перезапуск анимаций |

## Показ

Откройте любой `.html` в браузере, сервер не нужен.

- `→` / `пробел` / свайп — следующий слайд, `←` — предыдущий
- `R` — повторить анимацию, `F` — полный экран
- `Ctrl+P` → «Сохранить как PDF» — по слайду на страницу, без анимаций

## Как собрать свою презентацию

Скопируйте блоки `<section class="slide">…</section>` из шаблонов в один файл
(как в `index.html`) — порядок секций = порядок слайдов, номера страниц
проставятся автоматически.

## Анимации

Любому элементу внутри слайда добавьте класс `a` и тип анимации,
задержку — через `--d` (в секундах):

```html
<h2 class="a fade-up" style="--d:.3">Заголовок</h2>
```

Типы: `fade-up`, `fade-in`, `fade-left`, `fade-right`, `zoom-in`, `grow-x`,
`pop`, `draw` (для SVG-линий с `pathLength="1000"`).
При включённом в системе «уменьшении движения» анимации отключаются.

Цвета меняются в переменных `:root` в `assets/theme.css`.
