# Стратегическая сессия Домклик ВВБ — «Кино»

`strategic-session-kino.html` — готовая презентация одним файлом. Открывается двойным щелчком в Chrome или Edge, интернет не нужен: шрифты встроены.

- Титры: в режиме правки (E) они останавливаются — листайте колесом мыши, правьте имена, «+ добавить строку» добавляет новое имя.
- При открытии проектор ждёт команды: кнопка «Мотор!» или Пробел включают полный экран и запускают отсчёт 3·2·1. F — только полный экран, без запуска.
- Листать: → / Пробел / клик, назад: ←. Полный экран: F. Затемнение: B. Подсказка: H.
- Правка: E (или кнопка «✎ Правка» внизу): клик по тексту — править, клик по рамке фото — вставить снимок (можно перетащить файл), двойной клик — убрать.
- Ctrl+S — сохранить копию файла со всеми правками и фото.
- Новый слайд: в режиме правки кнопка «＋ Слайд» внизу добавляет слайд-конструктор после текущего — только заголовок, а элементы (текст, блок информации, карточки с цифрами, плитки, афиши, таблица, круговые показатели, вопросы, фото, спикеры, пьедестал, хлопушки, сценарий, развилка, итог) добавляются с панели. У каждого элемента при наведении: ＋/− пункт, цвет, ↑/↓, ✕. «▥ Колонки» — в одну или две колонки; лишнее содержимое само ужимается под кадр.
- Обновить движок в уже сохранённой копии (с вашими фото): `node kino/build.mjs && node kino/upgrade.mjs копия.html`.
- Ctrl+P — печать или PDF, по слайду на страницу.

Исходник — `src/deck.html`; сборка с встраиванием шрифтов: `node kino/build.mjs`.
